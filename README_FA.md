# راه‌اندازی ربات رایگان هشدار طلا در تلگرام

**نام:** Gold Telegram Alert Free v1.0  
**آخرین نسخه:** 16 October 2026  
**زبان نرم‌افزار:** Python 3.10+، فقط کتابخانه‌های پیش‌فرض؛ نصب pip لازم نیست.

## قبل از شروع (حتماً بخوان)

- این یک **ربات الگوریتمی مبتنی بر قوانین ثابت** است، **نه GPT یا هوش مصنوعی پیشرفته**. هیچ API پولی، اشتراک TradingView یا معامله‌گر خودکاری ندارد.
- منبع اولیه داده **Yahoo Finance با نماد `GC=F`، قرارداد آتی طلا COMEX** است؛ **قیمت آن با `XAUUSD` آلپاری یکسان نیست**، معمولاً تأخیر دارد، و دسترسی برنامه‌نویسی غیررسمی ممکن است محدود یا مسدود شود. عدد Entry/SL/TP در پیام فقط برای **GC=F** است؛ روی آلپاری بدون بررسی مستقیم وارد نکن.
- کندل‌ها در بازه ۱۵دقیقه بررسی می‌شوند، H1 و H4 جهت روند را بررسی می‌کنند. خبرهای زنده، نوسان اسپرد آلپاری، اسلیپیج و هزینه معامله بررسی نمی‌شوند. گزینه توقف دستی اخبار وجود دارد (`PAUSE_SIGNALS=true`).
- بررسی هر ۱۵ دقیقه **به معنی هشدار لحظه‌ای یا تضمین اجرای سر ساعت نیست**. اجرای زمان‌بندی‌شده GitHub گاهی دیر یا اصلاً اجرا نمی‌شود؛ Yahoo هم ممکن است پاسخ ندهد. ربات در این صورت معامله نمی‌کند و پیامی نیز ممکن است نرسد.
- این ابزار تحقیقاتی/آزمایشی است. قبل از هر استفاده عملی، چند هفته در دمو بررسی و با XAUUSD آلپاری مقایسه کن. **هیچ تضمینی برای نرخ برد و سود نیست**.

## چه چیزی در ZIP هست؟

- `bot.py`: تحلیل و ارسال پیام در تلگرام؛ شامل BUY, SELL, WAIT، RSI/ATR/ADX، EMA، کندل بسته‌شده و حد ضرر و دو هدف با نسبت 1.5 و 2.5.
- `.github/workflows/gold-alert.yml`: برنامه زمان‌بندی خودکار هر ۱۵ دقیقه (UTC)، و اجرای دستی setup، test، status، scan.
- `state.json`: ثبت آخرین سیگنال ارسال‌شده برای جلوگیری از پیام تکراری.
- `tests/test_bot.py`: تست بدون اتصال اینترنت.
- `.env.example`: فهرست تنظیمات اختیاری؛ حاوی توکن واقعی نیست.

## آموزش روی گوشی اندروید؛ بدون کامپیوتر

### مرحله ۱ — ربات تلگرام بساز

1. در تلگرام، حساب رسمی [@BotFather](https://t.me/BotFather) را باز کن.
2. `/newbot` را بفرست؛ یک نام و یک یوزرنیم که آخرش `bot` باشد انتخاب کن.
3. BotFather یک **Bot Token** می‌دهد. توکن را **در این چت برای من نفرست، داخل فایل، اسکرین‌شات، ریپوی عمومی یا پیام عمومی قرار نده**.
4. ربات تازه ساخته‌شده خودت را در تلگرام باز کن و دکمه **Start** یا پیام `/start` را بفرست. تا قبل از این کار، معمولاً ربات نمی‌تواند خصوصی به تو پیام بدهد.

### مرحله ۲ — مخزن GitHub بساز

1. اگر حساب نداری، در [github.com](https://github.com) حساب رایگان بساز.
2. روی `+` و `New repository` بزن. نام پیشنهادی `gold-telegram-alert-free` است. برای **اجرای بدون هزینه روی GitHub-hosted runner، Public انتخاب کن**. کد در ریپوی Public برای همه قابل مشاهده است، ولی توکن را در بخش Secrets نگه می‌داریم.
3. تیک `Add a README` را بزن و `Create repository` را انتخاب کن.
4. از این ZIP فایل‌های `bot.py` و `state.json` را روی گوشی استخراج کن. در GitHub، از `Add file → Upload files` آنها را بارگذاری و `Commit changes` کن.
5. در همان مخزن، `Add file → Create new file` را انتخاب کن. **نام فایل دقیقاً** این باشد:

   `.github/workflows/gold-alert.yml`

   محتوای فایل `.github/workflows/gold-alert.yml` که در ZIP دانلود کرده‌ای را داخل GitHub کپی کن؛ `Commit changes` بزن. (اگر به‌جای این کار توانستی کل پوشه `.github` را با مسیر صحیح بارگذاری کنی نیز مشکلی نیست.)
6. اگر دکمه‌ها در موبایل دیده نمی‌شوند، Chrome → منوی سه‌نقطه → `Desktop site` را فعال کن.

### مرحله ۳ — توکن را به شکل امن وارد کن

1. در مخزن GitHub وارد `Settings → Secrets and variables → Actions` شو.
2. روی `New repository secret` بزن.
3. `Name`: **`TELEGRAM_BOT_TOKEN`**
4. `Secret`: همان توکن BotFather؛ سپس `Add secret`.
5. **توکن را داخل `bot.py` یا متن Workflow نگذار**. Secret رمزگذاری و فقط هنگام اجرای Workflow وارد می‌شود.

### مرحله ۴ — شماره Chat ID را **خصوصی در تلگرام** دریافت کن

1. اگر هنوز `/start` را برای رباتت نفرستاده‌ای، الان بفرست.
2. در GitHub زبانه `Actions` را باز کن؛ اگر درخواست Enable workflows دیدی، آن را فعال کن.
3. Workflow `Gold Telegram Alerts (free)` را انتخاب و روی `Run workflow` بزن.
4. از فهرست `mode` گزینه **setup** را انتخاب و اجرا کن.
5. ربات باید **در چت خصوصی تلگرام خودت** پیام `Your private Telegram chat ID: ...` ارسال کند. کد طوری است که Chat ID را در لاگ عمومی مخزن چاپ نکند.
6. عدد را کپی کن و همانجا در `Settings → Secrets and variables → Actions` یک Secret دیگر بساز:
   - `Name`: **`TELEGRAM_CHAT_ID`**
   - `Secret`: عددی که در تلگرام گرفتی.

اگر پیام نرسید: به ربات درست `/start` بفرست، توکن را دوباره بررسی کن، و در Actions نتیجه اجرای setup و پیام خطا را ببین. هیچ‌وقت متن حاوی توکن را منتشر نکن.

### مرحله ۵ — آزمون اتصال و اسکن

1. در `Actions → Gold Telegram Alerts (free) → Run workflow` ابتدا `mode=test` را انتخاب کن. باید پیام «connected» در تلگرام برسد. این **سیگنال معامله نیست**.
2. سپس `mode=status` را اجرا کن تا وضعیت فعلی (ممکن است `WAIT` باشد) را دریافت کنی. **این مرحله به اینترنت و داده قابل دسترس از Yahoo نیاز دارد**؛ ممکن است به خاطر تأخیر/محدودیت منبع موفق نشود.
3. از این به بعد `mode=scan` خودکار حدود هر ۱۵ دقیقه اجرا می‌شود؛ **فقط** موقعیت تازه BUY یا SELL را ارسال می‌کند. اگر شرط تأیید نشود هیچ پیامی ارسال نمی‌کند.
4. برای توقف موقت: در GitHub → Actions → Workflow → منوی سه‌نقطه → `Disable workflow`. برای شروع مجدد `Enable workflow`.

## معنی یک پیام سیگنال

- **BUY / SELL**: نتیجه الگوریتم روی آتی طلای `GC=F`، نه دستور معامله در آلپاری.
- **WAIT**: روند تایم‌فریم‌ها، RSI/ADX یا کندل تأیید قابل قبول نبوده‌اند.
- **Entry**: قیمت بسته شدن کندل ۱۵دقیقه که سیگنال را تأیید کرده، **قیمت تضمینی قابل معامله نیست**.
- **SL**: براساس ATR و کف/سقف اخیر؛ ممکن است روی CFD آلپاری منطقی نباشد.
- **TP1=1.5R** و **TP2=2.5R**: صرفاً اهداف الگوریتم، نه پیش‌بینی قطعی.
- **H1/H4**: EMA21 در برابر EMA55 و شیب EMA؛ فقط کندل‌های بسته‌شده.

## امنیت و هزینه

- تلگرام برای ارسال پیام استاندارد با Bot API هزینه API نمی‌گیرد.
- GitHub Actions روی ریپوی **Public** با رانر استاندارد رایگان است. در ریپوی خصوصی، سهمیه زمان وجود دارد و اجرای هر ۱۵دقیقه ممکن است از سهمیه عبور کند.
- **محدودیت‌های GitHub:** اجرا می‌تواند عقب بیفتد یا به خاطر بار زیاد جا بیفتد؛ Workflowهای زمان‌بندی‌شده در ریپوهای عمومی بعد از **۶۰ روز بدون فعالیت ریپو** ممکن است خودکار غیرفعال شوند.
- `state.json` در ریپوی عمومی قابل مشاهده است و زمان آخرین هشدار را نشان می‌دهد؛ توکن و Chat ID نباید در آن ذخیره شوند.
- توکن BotFather را هیچ جا علنی نکن؛ اگر افشا شد، از BotFather توکن را لغو و دوباره بساز.
- این شیوه خدمات ۲۴ساعته تضمینی یا ارتباط واقعی با قیمت Alpari/MT5 نیست.

## اجرا روی کامپیوتر خودت (اختیاری)

اگر Python نصب داری و نمی‌خواهی از GitHub استفاده کنی، می‌توانی برنامه را محلی اجرا کنی. در این حالت برای هشدار پیوسته لازم است کامپیوتر روشن بماند و به اینترنت وصل باشد.

در Windows PowerShell:

```powershell
$env:TELEGRAM_BOT_TOKEN="YOUR_TOKEN"
$env:TELEGRAM_CHAT_ID="YOUR_CHAT_ID"
python bot.py --mode test
python bot.py --mode status
python bot.py --mode scan
```

برای دریافت Chat ID محلی ابتدا `$env:TELEGRAM_BOT_TOKEN` را تنظیم کن، به ربات `/start` بفرست و دستور `python bot.py --mode setup` را اجرا کن؛ Chat ID را **در تلگرام** دریافت می‌کنی.

تست‌های آفلاین:

```sh
python -m unittest discover -s tests -v
```

## امکان ارتقای بعدی

اگر بخواهی بعداً **قیمت دقیق نماد GLDUSD/XAUUSD آلپاری** بررسی شود، باید منبع دیتا را به ترمینال MT5 (یا API داده مجاز) وصل کنیم. در حالت MT5، اجرای مداوم به یک کامپیوتر روشن/VPS احتیاج دارد. این نسخه فعلاً به هیچ حساب بروکری وصل نمی‌شود و معامله‌ای باز نمی‌کند.
